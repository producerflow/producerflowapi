## Additional resources

- **Webhooks directory** — the [`/webhooks`](https://github.com/producerflow/producerflowapi/tree/main/webhooks) directory contains sample payloads and JSON schema files for validation.
- **Generated code** — the [`/gen`](https://github.com/producerflow/producerflowapi/tree/main/gen) directory contains generated client libraries for Go, TypeScript, and Kotlin.
